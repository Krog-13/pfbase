# PFBASE 🚀

PFBASE is a **minimal** project built on **Django REST Framework** for flexible backend development.

## ✨ About

PFBASE is designed around a **fixed model** approach and supports **dynamic table construction** without creating a separate Django model for every table.

It keeps things:
- **simple**
- **lightweight**
- **practical**
- **easy to extend** 🙂

## 🧩 Features

- ⚡ Built with **Django REST Framework**
-  **Fixed model** architecture
-  **Dynamic table construction**
-  No need to create models for every table
-  Minimalist structure
-  Clean and reusable project base
